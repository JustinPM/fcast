⚠️ HTTPS Mixed Content Restriction

Browsers block secure HTTPS websites (like GitHub Pages) from opening unencrypted ws:// connections to local IP addresses. Choose one of the solutions below:

Option 1: Allow Insecure Content in Chrome / Android (Quickest)
  1. Tap the Site Settings / Lock / Tune icon in your browser address bar.
  2. Tap Site Settings.
  3. Find Insecure Content and set it to Allow.
  4. Reload this page and connect again.
Option 2: Access App Over HTTP

Host or serve this single index.html file over plain http:// (e.g. using npx serve, Python python -m http.server, or local network IP). Browsers allow unencrypted ws:// when the app itself is served via HTTP.

Option 3: Use Secure WebSockets (wss://)

If your FCast receiver or a local reverse proxy (Caddy/Nginx) is configured with SSL/TLS certificates, switch the protocol dropdown to wss:// above.
